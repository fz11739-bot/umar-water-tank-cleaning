# Clean Spark

Create a modern, premium, fully responsive frontend website for Umar Water Tank Cleaning, based in Islamabad, Pakistan.



The website should have a clean, trustworthy, and professional look using a blue and white color palette. Focus on generating leads through Call and WhatsApp buttons.



Tech Stack



React.js (Vite)



Tailwind CSS



React Router



Framer Motion



Responsive on Mobile, Tablet & Desktop



SEO-friendly structure



Clean, reusable component architecture





Do NOT create any backend, database, authentication, or admin panel. Use dummy JSON data for all content.
